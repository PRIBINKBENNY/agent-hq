# UK ML / AI job market: what employers ask for

- Most-asked stack for junior/mid ML and AI engineer roles: production Python, SQL, LLM APIs, RAG, vector databases,
  agents with tool use, evaluation, and basic cloud deployment (Docker, CI/CD, one cloud). Classical ML fundamentals
  (metrics, bias/variance, overfitting) are still checked.
- Evaluation is the differentiator: postings ask candidates to define "good", build a test set and measure it. Score a
  role higher when Pribin's projects show a measured evaluation; recommend adding one when they do not.
- MLOps and LLMOps are splitting into two tracks. LLMOps = prompt/version management, eval harnesses, RAG infra, vector
  store ops, guardrails, agent runtimes. Classic MLOps = experiment tracking (MLflow), model versioning, monitoring,
  drift, cost and latency. Tag each role with which track it is.
- The entry-level bar is higher than before; many "junior" roles still want shipped systems. Fit scores must reflect the
  real ask (years, seniority), not the title.
- Pribin's angle: MSc AI & Robotics, YOLOv8/computer vision, Gait Guardian, and this agent office (a real multi-agent
  system with tools, shared memory, approvals and evals). Lead with shipped, measured systems.

builtinlondon.uk AI engineer listings, consultadd.com (AI/ML engineer 2026). Recruiter blogs: indicative, not official data.
