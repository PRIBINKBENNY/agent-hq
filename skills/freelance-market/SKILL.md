# Freelance AI / dev work market

- Strong demand for AI agent development and API/workflow integration; agent work appears on about a fifth of AI
  automation postings tracked on Upwork (May 2026). Fixed-price projects of $1k-5k are common.
- Indicative price bands (Upwork project tables): chatbot $500-2,000; workflow automation agent $2,000-5,000; custom
  LLM agent $5,000-15,000; multi-agent system $10,000-30,000. Hourly: median near $30 on marketplaces; specialist agent
  and orchestration work $60+; senior off-platform $150+.
- Agent architecture and integration earn a premium over no-code glue. Sell outcomes (hours saved, leads handled), show a
  working demo, and quote fixed scopes with a paid discovery step for anything vague.
- Pribin is early-career: price in the lower-middle of each band, lead with the agent office as proof, and never promise
  what the Studio has not scoped. Prices must come from workspace/offer.md.
